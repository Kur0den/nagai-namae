## なんかこういいかんじなやつ
1/2の確率で抽選をして当たっていれば選択肢の中からランダムなものを文字列の最後に追加するプログラム
### つかいかた
1. data.txtをプロジェクトのルートに用意して選択肢を改行区切りで入力
2. cargo run

https://social.vivaldi.net/@DozingCat/116369895548782646 の投稿などを見かけてインスピレーションが湧きました 
とうこうしてくれてありがとうございます

### data.txtの例
始まりの単語を `法人税施行令` に設定、終わりの単語を `を改正する政令` に設定したうえでお楽しみいただけます

```
及び法人税施行令
及び法人税施行令の一部
を改正する政令
の一部を改正する政令
```
